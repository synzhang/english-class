# 产品上下文

## 用户与需要

English Class 面向自主学习英语的中文使用者，主要是青少年和成人，起点为初级至中级。用户需要先理解句子在具体情境中的意思，再练习选择和使用形式；产品不应只要求背公式或靠时间词猜答案。

## 当前学习流程

1. 学习首页介绍平台，并进入当前开放的「语法与时态」模块。
2. 在时态目录中按时间组浏览 16 门课程。
3. 每课先理解用法和语境，再看肯定、否定、疑问句型及英文例句。
4. 在同一个练习区逐题完成导学题、三道递进巩固题和一道新语境迁移题。每题四个选项；作答后立即反馈正确性，并解释各选项与语境的关系。
5. 已答题、课程进度与错题可跨课程查看；错题复习后回到进入复习前的页面。
6. 练习库提供 16 题混合测验，每种形式抽取一道独立新题。

## 教学分类与准确性边界

- 课程目录采用便于学习的 16 种形式：现在、过去、将来时间表达、过去将来表达各四种。
- 这是学习分类，不是“英语有 16 个独立屈折时态”的语法结论。英语通过 will、be going to、现在进行时、一般现在时等结构表达将来时间。
- 过去将来从过去的参照点描述之后的预期、计划或安排。除 would 系列外，was / were going to 和过去进行时也可按语境表达相关意思。
- 解释要中文优先，英文例句自然、有上下文；时间表达只是线索，最终依据是语境和说话者的时间关系。
- 课程示例、练习题和迁移题应有不同语境；错选反馈需解释为何该形式不合适，而非只显示正确答案。

## 视觉与内容原则

- 整体是清晰、安静、容易浏览的英语课堂：冷白纸面、海军蓝文字、克制的教材蓝交互色，少量暖黄色作学习标记。
- 中文说明使用清晰的无衬线字体；英文例句和选项用 Lora 等衬线字体区分。
- 当前导航包括学习首页、练习库、错题复习；词汇、听力、阅读、口语、写作只作为规划项展示，不得伪装成可用功能。
- `PRODUCT.md` 和 `DESIGN.md` 是产品范围与视觉方向的详细依据；`docs/tenses/` 中的图表是参考材料，不是权威课程文案或语法来源。
