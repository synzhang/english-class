# 项目简报

## 项目

English Class 是面向中文使用者的英语自主学习 Web 应用。目标是让学习者理解语言形式与使用情境的关系，并能把所学迁移到新句子，而不只是记忆规则。

## 当前范围

- 一个平台首页和可扩展的学习模块目录。
- 当前交付模块为英语时态学习：16 种学习形式，按现在、过去、将来时间表达和过去将来表达分成四组。
- 每课有解释、句型、语境例句、五道递进练习和即时选项反馈；全模块有独立题目的混合练习与错题复习。
- 学习进度保存在浏览器本地，不要求账号或后端。

## 用户

自主学习英语的中文青少年和成人，预期初级至中级。

## 产品目标

- 先建立语境和意义，再介绍形式。
- 逐步从识别练习过渡到新语境迁移。
- 错误反馈具体说明选择为何适合或不适合。
- 让学习者知道当前已开放内容与规划中内容的区别。

## 范围边界

- 16 种是课程使用的教学分类，不声称英语有 16 种独立屈折时态。
- 现在实现的功能与 `PRODUCT.md` 中的远期平台方向要分开说明。
- 新模块、服务端账号和跨设备同步均不属于当前已实现范围。

## 依据优先级

1. 当前源码决定已实现的行为和数据契约。
2. `PRODUCT.md` 决定产品范围与学习要求；`DESIGN.md` 决定视觉方向和响应式约束。
3. `README.md` 用于快速了解和本地运行。
4. `docs/tenses/` 的图片仅是规划参考。英语语法内容应以可靠语法资料核对，不能把图表当作权威文案。
