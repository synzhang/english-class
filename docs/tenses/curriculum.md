# Tenses 课程大纲

## 课程目标

学完一课后，学习者能从语境判断目标形式表达的时间关系，理解肯定、否定和疑问句的基本结构，并在新语境中正确选用目标形式。目录采用面向学习者的 16 种常见形式，不把它说成唯一的语言学分类。

## 分类说明

本课程把内容分为现在时间、过去时间、将来时间表达和过去将来表达四组，每组四种常见学习形式。这里的 16 种是教学目录，不是英语有 16 种独立屈折时态的语言学主张。Cambridge 说明英语没有独立的将来时词形，而是通过多种结构表达将来时间；过去将来则从过去参照点看向之后的事件。目录最后四课用 would 与不同体貌结构组合来练习这一相对时间关系；*was / were going to* 和过去进行时也可按语境表达过去的计划或预期。

## 课程目录

| 学习组 | 课程 | 核心语境 | 肯定句结构 |
| --- | --- | --- | --- |
| 现在时间 | 一般现在时 | 习惯、普遍事实、固定安排 | 主语 + 动词原形（he / she / it + -s） |
| 现在时间 | 现在进行时 | 此刻正在发生、暂时状态 | 主语 + am / is / are + 动词-ing |
| 现在时间 | 现在完成时 | 过去事件与现在结果、经历或未结束时间段相关 | 主语 + have / has + 过去分词 |
| 现在时间 | 现在完成进行时 | 活动从过去持续到现在，强调过程或时长 | 主语 + have / has been + 动词-ing |
| 过去时间 | 一般过去时 | 过去已完成的动作、事件或状态 | 主语 + 动词过去式 |
| 过去时间 | 过去进行时 | 过去某时正在进行，或作为背景活动 | 主语 + was / were + 动词-ing |
| 过去时间 | 过去完成时 | 在另一个过去参照点之前已发生或完成 | 主语 + had + 过去分词 |
| 过去时间 | 过去完成进行时 | 活动持续到过去时点，强调时长或原因 | 主语 + had been + 动词-ing |
| 将来时间表达 | 一般将来时（will） | 预测、承诺、说话当下作出的决定 | 主语 + will + 动词原形 |
| 将来时间表达 | 将来进行时 | 未来某个时刻正在进行的活动 | 主语 + will be + 动词-ing |
| 将来时间表达 | 将来完成时 | 到未来参照点之前已完成的动作 | 主语 + will have + 过去分词 |
| 将来时间表达 | 将来完成进行时 | 到未来参照点时活动已持续的时长 | 主语 + will have been + 动词-ing |
| 过去将来表达 | 一般过去将来时 | 从过去参照点看，之后会发生或预计发生 | 主语 + would + 动词原形 |
| 过去将来表达 | 过去将来进行时 | 从过去看，之后某时正在进行 | 主语 + would be + 动词-ing |
| 过去将来表达 | 过去将来完成时 | 从过去看，之后某时前已完成 | 主语 + would have + 过去分词 |
| 过去将来表达 | 过去将来完成进行时 | 到过去预期的较晚时点，活动已持续一段时间 | 主语 + would have been + 动词-ing |

每种形式的否定和疑问结构、完整例句，以及五道练习题见 `src/features/tenses/lesson-data.ts` 与 `src/features/tenses/practice-sets.ts`。每课包括 1 道导学题、3 道递进巩固题和 1 道新语境迁移题；每题均有 4 个有针对性的选项及逐项解析。五题合并在同一个练习区，每次只显示一道；前四题答对后进入下一题，最后一题答对后显示本课完成状态。16 课共 80 题。课程大纲本身不替代编辑审校。

## 单课教学节奏

1. **理解语境**：先说明动作发生的时间以及句子想表达的重点。
2. **掌握结构**：展示肯定句、否定句、疑问句，并给出一个自然例句和中文释义。
3. **逐题练习**：导学题与 3 道巩固题依次出现，每次只展示一道；导学题换用不同的人物和场景，不复述讲解例句；4 个选项覆盖目标形式和容易混淆的相近形式，答对后进入下一题。
4. **迁移检验**：作为同一练习区的最后一题，换人物与场景，独立判断能否在新语境中使用目标形式；每个选项都说明成立或不合语境的原因。
5. **错题复习**：保留答错记录，并按课程名称呈现全目录的错题。


时间副词或时间短语只作为线索之一。课程需要同时解释动作含义、参照时间和语篇语境，避免把 *every day* 或 *right now* 教成自动选时态的规则。

## 教学与编辑注意

- 区分现在完成时所表达的结果或经历，与现在完成进行时对持续活动过程或时长的强调；实际使用有重叠，不能把差异简化为“完成/没完成”。
- 区分过去完成时的先后关系和过去完成进行时的持续过程；不是每段过去叙事都需要过去完成时。
- *will* 是情态动词，未来时间还可由 *be going to*、现在进行时和一般现在时表达；根据计划、安排、预测和说话意图讲解选择。
- 将来完成时态的教程材料常按熟悉的教学术语命名；说明学习用语与严格形态分类之间的差异。
- 四个选项要围绕目标形式与容易混淆的时间、体貌或参照点设计；难度来自辨析，不靠歧义或冷僻词。
- 题目需避免多个选项在给定语境里都自然成立。若自然英语允许多种说法，要改写语境或明确题目观察点。
- 每道题都为四个选项提供独立反馈，说明目标答案为何合适，以及各干扰项为何不合语境。
